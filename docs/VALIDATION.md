## Live Instagram verification

Live smoke testing was attempted again on October 2, 2026, including the reported comment post `https://www.instagram.com/p/DLu_fkMszQQ/`. The web fetch of that post was throttled. Access to the existing signed-in Chrome profile was blocked by the computer-use tool: `Sky Computer Use native pipe startup failed`. No live follower, following, post, reply or liker endpoint/layout is claimed as verified. Reattaching to a tab kept open across an actual extension reload still needs a manual check: calling runtime.reload in the command-line-loaded Chromium test installation unloads the extension rather than bringing its worker back. Only the in-app browser and MCP Apps surface were available; the signed-in Chrome profile could not be reached. Instagram's undocumented browser endpoints may need adapter updates for the current session or response format.

For a manual smoke test, sign into Instagram in the same Chrome profile and reload the unpacked extension in place. Open a small accessible profile, click the toolbar icon and collect Followers, then Following. Verify sole-mission selection is hidden; with multiple missions, choose one. Collect Commenters and Likers from a post and a profile, including reels/replies where accessible. Confirm the bottom-right overlay opens the selected list and that native requests and coverage match saved results. Turn Automatic off for manual capture. Close the main app and leave the Instagram tab open, then reopen the app from the popup and confirm collection/decisions are preserved. Reload Instagram and explicitly resume through the popup, checking deduplication. Direct collection is available only from the main Add source flow and has its own cooldown. Pause on Instagram and use the overlay Resume button, verifying that the document remains open. Lists with saved data continue without repeating the initial page; an empty likes list closes and reopens through normal controls to recapture page one. Check completion versus partial status and saved-result reuse. Perform challenges on Instagram itself before resuming; do not override a cooldown.
